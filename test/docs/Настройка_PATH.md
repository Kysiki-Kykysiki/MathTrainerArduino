# Как добавить PlatformIO (`pio`) в PATH на Windows

Чтобы команда `pio` работала из любой папки (а не по полному пути), нужно
добавить папку с исполняемым файлом PlatformIO в переменную среды **PATH**.

---

## 1. Где лежит `pio`

При установке PlatformIO Core кладёт `pio.exe` сюда:

```
C:\Users\<ИМЯ_ПОЛЬЗОВАТЕЛЯ>\.platformio\penv\Scripts
```

> На этом компьютере это:
> `C:\Users\Kysb\.platformio\penv\Scripts`

Проверить, что файл там есть, можно в PowerShell:

```powershell
Test-Path "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe"
```
Должно вывести `True`.

---

## 2. Быстрая проверка без PATH

Пока PATH не настроен, можно запускать по полному пути:

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" test -e native
```

---

## 3. Способ A — через графический интерфейс Windows (рекомендуется)

1. Нажмите **Win**, наберите «**Изменение переменных среды учётной записи**»,
   откройте этот пункт.
2. В окне «Переменные среды» в верхнем списке (для пользователя) выберите
   **Path** → кнопка **Изменить…**
3. Нажмите **Создать** и вставьте путь:
   ```
   C:\Users\Kysb\.platformio\penv\Scripts
   ```
   (замените `Kysb` на своё имя пользователя, если отличается)
4. **ОК → ОК → ОК**.
5. **Закройте и заново откройте** терминал / VS Code (важно — иначе PATH не
   обновится).
6. Проверьте:
   ```powershell
   pio --version
   ```
   Должно показать версию, например `PlatformIO Core, version 6.1.19`.

---

## 4. Способ B — командой PowerShell (для пользователя, без прав администратора)

Добавляет путь в PATH **текущего пользователя** навсегда:

```powershell
$pioPath = "$env:USERPROFILE\.platformio\penv\Scripts"
$old = [Environment]::GetEnvironmentVariable("Path", "User")
if ($old -notlike "*$pioPath*") {
    [Environment]::SetEnvironmentVariable("Path", "$old;$pioPath", "User")
    Write-Host "Путь добавлен. Перезапустите терминал."
} else {
    Write-Host "Путь уже есть в PATH."
}
```

После этого **перезапустите терминал** и проверьте `pio --version`.

---

## 5. Способ C — только на время текущей сессии терминала

Если нужно «здесь и сейчас», без постоянных изменений:

```powershell
$env:Path += ";$env:USERPROFILE\.platformio\penv\Scripts"
pio --version
```

> Это действует только до закрытия окна терминала.

---

## 6. Альтернатива — расширение PlatformIO IDE в VS Code

Если установить расширение **PlatformIO IDE** в VS Code, отдельно настраивать
PATH не обязательно: тесты можно запускать кнопкой на панели PlatformIO
(значок инопланетянина) → раздел **Advanced → Test**, либо во встроенном
терминале VS Code команда `pio` будет доступна автоматически.

---

## 7. Если `pio` всё равно не находится

- Убедитесь, что **закрыли и открыли заново** терминал после изменения PATH.
- Проверьте правильность имени пользователя в пути.
- Проверьте, что PlatformIO вообще установлен (см. раздел 1).
- В крайнем случае пользуйтесь полным путём (раздел 2) — это рабочий вариант.
